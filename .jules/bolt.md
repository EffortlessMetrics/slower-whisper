## 2025-02-28 - Vectorize streaming ASR frame-wise energy calculations
**Learning:** Python for-loops over NumPy array slices are slow. When analyzing streaming audio frames (e.g. for VAD), iterating frame-by-frame and calculating energy incurs high Python overhead.
**Action:** Use NumPy vectorization: reshape the 1D audio array into a 2D array of `(num_frames, frame_size)` and compute metrics using `axis=1`. This provides significant C-level speedups (~14x faster). Note that `.tolist()` on NumPy boolean arrays returns `list[Any]`, so use a list comprehension like `[bool(x) for x in boolean_array]` to satisfy strict mypy `list[bool]` types.
