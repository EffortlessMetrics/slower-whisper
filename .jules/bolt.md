## 2024-05-15 - [Optimization: Avoid Redundant Subprocess Calls for FFMpeg]
**Learning:** During batch processing, checking if `ffmpeg` is available or retrieving its version on every file iteration adds up significant redundant I/O (stat) and costly subprocess spawning, creating a performance bottleneck. Caching these with `lru_cache` provides a measurable speedup. Additionally, testing functions decorated with `lru_cache` requires an `autouse=True` pytest fixture to manually clear the cache before and after tests to prevent state leakage and mock contamination across tests.
**Action:** Always apply `functools.lru_cache` to environment capability checks (like availability or version checks of external binaries) to prevent repetitive OS-level operations. Use an `autouse=True` fixture in the test file to clear the cache via `func.cache_clear()` to ensure tests run in isolation.
